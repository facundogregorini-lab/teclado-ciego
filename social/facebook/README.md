# Templo Ninja · primeros contenidos para Facebook

Kit inicial de cuatro publicaciones para presentar **Templo Ninja** y llevar personas a Teclado Ciego.

## Identidad de la serie

- **Promesa:** entrenar habilidades concretas, medir el progreso y superarse.
- **Tono:** desafiante, cercano y lúdico; nunca agresivo ni exagerado.
- **Paleta:** tinta `#141A21`, jade `#0B6E69`, arena `#F4EBDD`, oro `#E0A126` y coral `#C64E6A`.
- **Formato:** originales SVG cuadrados de 1080 × 1080 px y una página para descargarlos como PNG.
- **CTA común:** `Entrená gratis`.

Abrí `descargar.html` desde un servidor local o desde el sitio publicado para previsualizar las cuatro piezas y descargarlas como PNG. Los `.svg` son los originales editables y no hay binarios en el repositorio.
